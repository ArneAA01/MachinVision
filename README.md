## Project Description
This project uses PyTorch and ONNX to train and deploy a machine learning model for detecting fish species from images. 
The model is trained on an open-source dataset and returns predicted fish species together with a confidence score.
The project also includes data augmentation techniques to improve the robustness of the image recognition model. 
By applying transformations such as changes in lighting, rotation, scaling, and other image variations, the model becomes better at handling real-world image conditions.
